### ◈　关于我

你好，我是 **陈平（Chen Ping）**。

我是一名 **文科学生**，习惯在阅读与书写中理解世界，  
也愿意在安静处把纷杂的念头慢慢理清。

对人文、历史与表达抱有长久的兴趣——  
相信文字能够照见人心，思辨能够抵达更远的地方。
